# Portafolio — Harold Andrey Ramírez Muñoz

Portafolio personal que exhibe mi trabajo como desarrollador fullstack. Construido con React y Vite.

## Descripción general

Este proyecto funciona como demostración técnica de mis capacidades en desarrollo web moderno. Implementa una arquitectura limpia con principios de diseño responsivo y optimización de rendimiento.

## Stack tecnológico

### Tecnologías principales
- **Framework**: React 18 con TypeScript
- **Herramienta de construcción**: Vite 5
- **Estilado**: Tailwind CSS con sistema de diseño personalizado
- **Enrutamiento**: React Router DOM
